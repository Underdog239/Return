？ How to use

Getting started

  1. Instant Browser Mode: Click Launch instant 3D demo bot (or choose 3D Browser Sandbox in New Bot) to watch and control an AI bot right in your browser with zero setup.
  2. Real Minecraft Java Server (up to 1.21.11): Run ./start.sh (or cd mindcraft && npm install && node main.js) on your machine, start your Minecraft Java server or LAN world, and connect via New Bot.
  3. Watch the live camera feed and talk to your bot in the chat panel.

Talking to the bot

  • Plain language goes to the bot's AI mind — it thinks, replies, and picks actions: “go find diamonds”, “build a shelter”, “bridge across the river”.
  • Commands run instantly: !collectBlocks("oak_log", 10), !pvp("@hostile"), !bridgeTo(0, 64, 12), !goToCoordinates(15, 64, -10).
  • Autonomous mode gives it a goal it works on by itself: !selfPrompt("build a farm").

Smart movement

  • Navigation automatically sprints, jumps, breaks obstacles, bridges gaps with blocks from the bot's inventory, and finds alternative routes when blocked.
  • !bridgeTo(x, y, z) forces manual sneaky-bridging across ravines.

Fighting & gathering

  • !pvp("@hostile") / !pvp("@player") / !pvp("Steve") — advanced combat: strafing, crits, retreat & eat, creeper dodging.
  • !hunt(5) — hunts animals, cooks meat. !collectBlocks("stone", 64) — mines with best tools.

Camera

  • Drag to orbit, scroll to zoom, press P or click 👁 POV for first-person view.
